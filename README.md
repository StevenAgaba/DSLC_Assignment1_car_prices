## Overview
This project analyses an automobile dataset to identify the key factors influencing vehicle prices using data cleaning, exploratory data analysis (EDA), visualisation, and feature selection techniques.

## Dataset
- Dataset: `automobileEDA.csv`
- Target Variable: `price`

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Tasks Completed
### 1. Data Cleaning
- Checked and handled missing values
- Identified and removed duplicates
- Detected and treated outliers
- Saved a cleaned dataset

### 2. Exploratory Data Analysis
- Generated descriptive statistics
- Analysed variable distributions
- Created histograms, boxplots, and heatmaps

### 3. Group Analysis
- Compared average prices by:
  - Drive wheels
  - Body style
- Created pivot tables and heatmaps

### 4. Relationship Analysis
- Assessed the impact of continuous variables on price
- Assessed the impact of categorical variables on price
- Examined combined categorical effects

### 5. Feature Selection
- Identified variables with the strongest influence on price
- Applied correlation analysis and feature importance techniques

## Key Findings
The most influential variables affecting automobile price were:

- Engine Size
- Horsepower
- Curb Weight
- Vehicle Width

Fuel economy measures showed a negative relationship with price.

## Recommendation
Car dealers should prioritise engine size, horsepower, and vehicle weight when pricing vehicles, as these factors have the strongest impact on market value.
